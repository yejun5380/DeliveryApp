[열람 방법]
ZIP을 모두 해제하고 PDF는 일반 PDF 뷰어로 연다. 맑은 고딕이 내장되어 있다.
발표는 05_발표자료/의 HTML을 브라우저에서 직접 연다.
4주차는 방향키·마우스 휠, 5·7·8주차는 스크롤·방향키·Page Up/Down·스페이스 지원.
5·7·8주차의 실행 화면은 클릭하여 확대할 수 있다.
HTML과 images/를 함께 유지한다. 발표 PDF 변환본은 별도로 제공하지 않는다.

[서비스 및 검증 범위]
실제 결제·배달이 없는 가상 주문 및 절약 기록 서비스다.
5km는 임의의 가상 기준이며 실제 도로거리·배달 영업 가능 여부를 뜻하지 않는다.
코드 분석, 실제 함수의 격리 검증, 제공 실행 화면을 구분하여 기술했다.
운영 DB 스키마 및 실제 DB/API 통합 검증은 수행하지 않았다.
이 묶음은 보고서·발표자료용이며 실행 가능한 Flask 서버 배포 패키지가 아니다.

[파일 구성 원칙]
개발 소스·원본 SQL·DB 덤프·.env·실제 비밀번호·API 키는 포함하지 않는다.
데이터 사전의 password 등은 컬럼명이며 비밀값이 아니다.
학번·이름 및 제출 플랫폼의 업로드 용량 제한을 확인한다.

[최종 검증 완료]
- 보고서 PDF 4개, 총 19쪽: Poppler 렌더링으로 모든 페이지 시각 확인.
- 한글 폰트 내장, 학번·이름·페이지 번호, 텍스트 페이지 경계 검사 완료.
- 원본 발표 HTML 4개 바이트 동일 확인 및 로컬 상대경로·이미지 검증 완료.
- 헤드리스 Edge에서 4·5·7·8주차 이미지 로딩과 방향키 이동 확인.
- 브라우저 JavaScript 오류 없음. DB/API 통합 테스트를 의미하지 않음.
- 분석 대상 원본 파일 SHA-256 동일 확인. 기존 코드·SQL·발표 변경 없음.
- 최종 ZIP의 전체 항목과 CRC, 압축본과 파일의 바이트 일치 검증 완료.
