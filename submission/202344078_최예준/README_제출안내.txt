[발표자료 열기]
압축을 먼저 모두 해제한 후 05_발표자료/ 안의 HTML을 브라우저로 연다.
4주차 파일: 방향키 또는 마우스 휠, 전체 화면 버튼.
5·7·8주차 파일: 스크롤, 방향키, Page Up/Down, 스페이스. 캡처 클릭 시 확대.
HTML 원본은 바이트 단위로 동일하게 복사했다.
5주차 HTML의 내장 이미지에서 images/address.png, delivery.png, map.png를
추출해 함께 제공했다. 기존 상대경로와 내장 fallback 모두 유지된다.
발표자료는 상호작용 보존을 위해 HTML로 제공하며 별도 PDF 변환본은 없다.

[정확성 및 누락 안내]
week4_presentation.html의 본문 제목은 3주차이다. 원본을 수정하지 않았다.
README의 주소·지도 개발 주차는 4주차, 해당 발표는 5주차로 표기되어 있다.
week1/2/3/6_presentation.html은 발견되지 않았다. 임의 생성하지 않았다.
presentation/index.html은 현재 프로젝트에 없다. 발표는 개별 HTML로 연다.
restaurants.address 및 orders.delivery_address 추가 DDL이 저장소에 없으며
정확한 타입·제약과 운영 DB 적용 상태는 확인하지 못했다.
static/ 폴더는 현재 프로젝트에 없다. 문서에는 존재한다고 기재하지 않았다.
기존 DB/API 통합 실행 테스트를 새로 수행하지 않았다.
3.75km 사례는 제공된 특정 테스트 캡처이며 모든 회원의 공통 결과가 아니다.

[보안 및 원본 보존]
.env, 비밀번호·API 키 값, 원본 app.py·SQL 데이터·DB 덤프는 포함하지 않았다.
보고서의 컬럼명 password는 데이터 사전 항목이며 실제 비밀번호가 아니다.
DB 초기화·SQL 실행·원본 코드 변경 없이 보고서와 복사본만 생성했다.
소스 구현 확인, 20개 JavaScript 격리 검증, 제공 화면 확인을 구분했다.
이 ZIP은 보고서·발표 제출 묶음이며 애플리케이션 실행 배포 패키지는 아니다.

[제출 전 확인]
학번·이름 및 제출 플랫폼의 파일 크기 제한을 확인한다.
PDF는 맑은 고딕을 내장했으므로 별도 폰트 설치 없이 읽을 수 있다.
