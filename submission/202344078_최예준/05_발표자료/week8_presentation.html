02 / HAVERSINE

위도·경도로 구하는 직선거리

입력

배달 주소 좌표 + 음식점 좌표
위도·경도를 라디안으로 변환

계산

Haversine으로 중심각 계산
지구 반지름 6,371km 적용

거리(km) = 지구 반지름 × 중심각지도 좌표 사이의 지표면상 최단거리로 근사

직선거리 기준이며, 실제 도로 이동거리는 아닙니다.

03 / JAVASCRIPT

좌표 저장부터 거리 출력까지

04 / VIRTUAL RULE

5km를 기준으로 가상 판정

거리 ≤ 5km

가상 배달 가능

5km 경계값도 포함

거리 > 5km

가상 배달 범위 초과

기준을 넘으면 초과 문구 표시

5km는 프로젝트에서 임의로 설정한 가상 기준입니다.

반올림 전 거리로 판정하고, 표시는 소수점 둘째 자리까지 출력합니다.
주문을 차단하지 않고 배달현황 화면에 표시하며, 실제 배달 가능 여부를 확인하지는 않습니다.
