02 / DATABASE JOIN

주문에서 음식점까지 연결

  1. ordersid → order_items.order_id
  2. order_itemsmenu_id → menus.id
  3. menusrestaurant_id → restaurants.id
  4. restaurants음식점 이름·주소 조회

필요한 음식점만

주문 ID로 범위 제한
DISTINCT r.name, r.address

주소가 있는 음식점만

IS NOT NULL
TRIM(address) <> ''

라우트에서는 orders로 본인 주문을 먼저 확인한 뒤, 나머지 3개 테이블을 JOIN합니다.
DISTINCT는 같은 이름·주소 조합의 중복을 제거합니다.

03 / FLASK → MAP

Flask에서 카카오맵으로

  1. 주문 확인/delivery/<int:order_id>
  2. 목록 전달restaurants → 템플릿
  3. JavaScript 변환tojson으로 이름·주소 전달
  4. 주소 검색Geocoder.addressSearch()

주소 검색 성공 → 위도·경도 생성 → 음식점별 마커

주문의 배달 주소도 별도로 검색해 기존 마커를 유지합니다.

04 / MARKERS & BOUNDS

배달 주소와 음식점 위치를 한눈에

  • 여러 음식점이면 각각 마커 표시
  • 마커 클릭 → 음식점 이름 정보창
  • 성공한 좌표를 LatLngBounds에 추가
  • 전체 검색 완료 후
    map.setBounds()

표시 사례: 배달 주소 1곳 + 주문 음식점 여러 곳을 같은 지도에서 확인

05 / RESULTS

구현 결과 및 예외 처리

01

02

좌표 검색 처리

03

지도 범위 조정
