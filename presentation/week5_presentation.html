  • Kakao Maps JavaScript SDK
    services 라이브러리 사용

  • Geocoder로 주소를
    위도·경도로 변환

  • 사용자 배달 위치에 마커 표시

05 / TROUBLESHOOTING

구현 중 발생한 문제

문제 01

주소 미등록 상태에서 주문

주소 없이 주문하면
저장할 배달 주소가 없음

해결 ↓

주문 전에 주소를 확인하고,
미등록 시 주소 설정 페이지로 이동

주소 확인 → 미등록 시
주소 설정 페이지 이동

문제 02

주소 변경 시 기존 주문 주소 유지

사용자 주소를 바꾸면 기존 주문의
주소까지 변경되어 보일 수 있음

해결 ↓

현재 주소: users.address
주문 당시: orders.delivery_address

현재 주소와 주문 당시 주소를
분리하여 저장

문제 03

새로고침 시 배달 상태 초기화

단순 타이머는 새로고침하면
‘주문 접수’부터 다시 시작할 수 있음

해결 ↓

DB의 order_date와 현재 시간의
차이로 배달 상태 계산

order_date 기준으로
현재 배달 상태 복원
