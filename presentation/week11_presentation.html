02 / ORDER MANAGEMENT

주문 취소 및 재주문

주문 취소

  • 본인 주문만, 가상 배달 완료 전 취소
  • 취소 시각과 기록 보관 · 절약 통계 제외

재주문

  • 현재 지점과 가격을 확인해 장바구니에 다시 담기
  • 장바구니에서 사용자가 주문을 확정하면 새 주문 생성

03 / VIRTUAL WALLET

가상 배달 완료 후 포인트 적립

  • 완료 후 저금통·배달현황 조회 시 적립
  • 주문 금액만큼 가상 포인트 지급
  • MySQL에 잔액과 적립 내역 저장
  • 주문당 적립 기록 1건으로 중복 방지

절약 통계에는 배달 중인 정상 주문도 포함됩니다. 저금통에는 배달 완료 후 적립된 포인트만 반영됩니다.
