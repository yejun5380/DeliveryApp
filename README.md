# DeliveryApp - 가상 배달 주문 & 절약 관리 웹 서비스

 배달 앱 서비스 구조를 참고하여 제작한 가상 주문 서비스로, 주문 금액과 칼로리를 기록하여 '절약한 금액'과 '절약한 칼로리'를 시각화해 주는 웹 애플리케이션

---

## 1. 프로젝트 개요
* **진행 기간**: 2026년 2학기 개인 프로젝트
* **핵심 아이디어**: 실제 배달 주문 대신 가상의 주문을 진행하며 사용자가 음식 주문으로 지출하는 비용과 칼로리를 얼마나 줄였는지 계산해 줍니다.

---

## 3. 프로젝트 폴더 구조

```text
프젝/
├─ app.py               # Flask 백엔드 서버 메인 파일
├─ memo.txt             # 프로젝트 개발 노트
├─ DB/
│  └─ schema.sql        # 데이터베이스 생성 및 테이블 스키마 SQL
└─ templates/           # HTML 화면 템플릿 폴더
   ├─ index.html        # 메인 화면 (음식점 목록 및 검색)
   ├─ restaurant.html   # 음식점 상세 정보 및 메뉴 선택
   ├─ cart.html         # 장바구니 화면
   ├─ order_complete.html# 주문 완료 안내 화면
   ├─ orders.html       # 사용자 주문(절약) 내역 화면
   ├─ saving.html       # 절약 통계 화면
   ├─ signup.html       # 회원가입 화면
   └─ login.html        # 로그인 화면

```

## 주차별 개발 진행 상황

### 1주차: 프로젝트 기획 및 기본 구조 설계
- **프로젝트 기획**: 배달 절약 앱 'DeliveryApp' 아이디어 선정 및 기능 정의
- **화면 설계를 위한 레이아웃 구현**: HTML/CSS 기반 주요 페이지 틀 작성
- **데이터베이스(DB) 설계**:
  - MySQL Workbench를 활용한 ERD 작성
  - `users`, `restaurants`, `menus`, `orders`, `order_items` 테이블 구조 설계
  - 메뉴 가격/칼로리 변동 시 과거 기록 보존을 위한 `order_items` 독립 설계

---

### 2주차: 백엔드 연동 및 핵심 기능 구현
- **Flask & MySQL 연동**: 데이터베이스 접속 설정 및 `.env` 환경변수 처리
- **회원 관리 기능**:
  - 비밀번호 해시 암호화 적용 회원가입
  - Flask Session을 활용한 사용자 로그인/로그아웃 및 개별 사용자 데이터 구분
- **조회 및 검색 기능**:
  - DB 연동 음식점 목록 표시 및 상세 메뉴/칼로리 조회
  - 엔터(Enter) 키 입력 기반 음식점/메뉴 검색 기능 구현
- **가상 주문 및 데이터 처리**:
  - 장바구니 담기 및 가상 주문 기능 구현
  - 주문 발생 시 `orders` 및 `order_items` 테이블 데이터 저장 및 장바구니 초기화
- **절약 통계 페이지**:
  - Session의 `user_id` 기준 사용자별 총 절약 금액 및 총 절약 칼로리 계산 및 출력

---

**장바구니 세부 기능 구현**: 수량 증가/감소, 단일 항목 삭제 기능 추가
**실시간 금액 계산**: 수량 변경에 따른 총 금액 및 총 칼로리 즉시 반영
**예외 처리 & 안내**: 빈 장바구니 주문 방지 및 주문 전 확인 안내 창(Confirm) 추가
**주문 내역 상세화**: `orders.html`에서 날짜별 주문 메뉴, 수량, 가격/칼로리 상세 레이아웃 출력
**로그인 권한 제어**: 비로그인 사용자의 회원 전용 페이지(`/cart`, `/orders`, `/saving`) 접근 제한
**입력값 검증**: 회원가입 시 아이디 중복 확인 및 필수 항목 입력 검증
**에러 처리**: DB 연동 시 예외 상황에 대한 안내 메시지(Flash Message) 처리
