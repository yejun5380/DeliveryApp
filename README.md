# DeliveryApp - 가상 배달 주문 & 절약 관리 웹 서비스

 배달 앱 서비스 구조를 참고하여 제작한 가상 주문 서비스로, 주문 금액과 칼로리를 기록하여 '절약한 금액'과 '절약한 칼로리'를 시각화해 주는 웹 애플리케이션

---

## 프로젝트 개요
* **진행 기간**: 2학기 개인 프로젝트
* **핵심 아이디어**: 실제 배달 주문 대신 가상 주문을 통해 배달 지출을 방지하고, 절약한 비용과 섭취를 참아낸 칼로리를 시각적으로 보여줍니다

---

## 프로젝트 폴더 구조

```text
프젝/
├─ app.py               # Flask 백엔드 서버 메인 파일
├─ memo.txt             # 프로젝트 개발 노트
├─ DB/
│  └─ schema.sql        # 데이터베이스 생성 및 테이블 스키마 SQL
└─ templates/           # HTML 화면 템플릿 폴더
   ├─ index.html        # 메인 화면 (음식점 목록 및 검색)
   ├─ restaurant.html   # 음식점 상세 정보 및 메뉴 선택
   ├─ cart.html         # 장바구니 화면
   ├─ order_complete.html# 주문 완료 안내 화면
   ├─ orders.html       # 사용자 주문(절약) 내역 화면
   ├─ order_detail.html    # 개별 주문 상세 화면 
   ├─ saving.html       # 절약 통계 화면
   ├─ signup.html       # 회원가입 화면
   └─ login.html        # 로그인 화면

```

## 주차별 개발 진행 상황

### 1주차: 프로젝트 기획 및 기본 구조 설계

- **프로젝트 기획**: 배달 절약 앱 'DeliveryApp' 아이디어 선정 및 기능 정의
- **화면 설계를 위한 레이아웃 구현**: HTML/CSS 기반 주요 페이지 틀 작성
- **데이터베이스(DB) 설계**:
  - MySQL Workbench를 활용한 ERD 작성
  - `users`, `restaurants`, `menus`, `orders`, `order_items` 테이블 구조 설계
  - 메뉴 가격/칼로리 변동 시 과거 기록 보존을 위한 `order_items` 독립 설계

---

### 2주차: 백엔드 연동 및 핵심 기능 구현

- **Flask & MySQL 연동**:
  - 데이터베이스 접속 설정
  - `.env` 환경변수를 활용한 DB 접속 정보 관리

- **회원 관리 기능**:
  - 회원가입 기능 구현
  - 비밀번호 해시 암호화 적용
  - Flask Session을 활용한 로그인/로그아웃 기능 구현
  - 사용자별 데이터 구분

- **조회 및 검색 기능**:
  - DB에 저장된 음식점 목록 표시
  - 음식점별 메뉴 및 칼로리 조회
  - 음식점 이름 및 메뉴 이름 검색 기능 구현

- **장바구니 기능**:
  - 메뉴 장바구니 담기
  - 동일 메뉴 수량 증가
  - 수량 증가/감소 기능
  - 장바구니 개별 메뉴 삭제
  - 수량에 따른 총 금액 및 총 칼로리 계산
  - 빈 장바구니 주문 방지

- **가상 주문 및 데이터 처리**:
  - 실제 결제 없이 가상 주문 기능 구현
  - 주문 발생 시 `orders` 테이블에 주문 정보 저장
  - `order_items` 테이블에 메뉴, 수량, 가격, 칼로리 저장
  - 주문 완료 후 장바구니 초기화

- **절약 통계 기능**:
  - Session의 `user_id`를 기준으로 사용자별 데이터 조회
  - 사용자별 총 절약 금액 계산
  - 사용자별 총 절약 칼로리 계산

---

### 3주차: 주문 상세 기능 및 예외 처리 개선

- **주문 상세보기 기능 구현**:
  - 주문번호를 기준으로 개별 주문 상세 페이지 구현
  - 주문한 음식점, 메뉴, 수량 표시
  - 메뉴별 가격 및 칼로리 표시
  - 주문 전체 금액 및 전체 칼로리 표시
  - 로그인한 사용자가 자신의 주문만 조회할 수 있도록 권한 확인

- **절약 통계 기능 개선**:
  - 총 가상 주문 횟수 표시
  - 총 절약 금액 및 총 절약 칼로리 표시
  - 주문 기록이 없는 경우 안내 메시지 표시
  - 절약 통계 페이지에서 주문(절약)내역 및 홈으로 이동 기능 추가

- **주문 완료 페이지 개선**:
  - 방금 완료한 가상 주문의 절약 금액 표시
  - 방금 완료한 가상 주문의 절약 칼로리 표시
  - 주문내역 및 절약 통계 페이지 이동 기능 추가
  - 실제 가상 주문을 거치지 않고 주문 완료 페이지에 직접 접근하는 경우 주문내역으로 이동

- **장바구니 기능 개선**:
  - 장바구니가 비어 있는 경우 안내 메시지 표시
  - 장바구니에서 `다른 메뉴 더 보기` 기능 추가
  - 메인 화면에서 장바구니 페이지로 이동할 수 있도록 메뉴 추가
  - 로그아웃 시 장바구니 데이터 초기화
  - 다른 사용자 계정으로 이전 사용자의 장바구니가 전달되지 않도록 처리

- **회원가입 예외 처리**:
  - 기존 아이디 존재 여부 확인
  - 중복 아이디 회원가입 방지
    
- **로그인 권한 제어 강화**:
  - 비로그인 사용자의 장바구니 메뉴 추가 제한
  - 비로그인 사용자의 `/cart` 접근 제한
  - 비로그인 상태에서 장바구니 수량 변경 및 삭제 제한
  - `/orders`, `/saving` 등 사용자별 페이지 접근 시 로그인 여부 확인

- **주문내역 페이지 개선**:
  - 주문 목록에서 개별 주문 상세 페이지로 이동 가능
  - 주문내역에서 홈 화면으로 이동 기능 추가
  - 주문 기록이 없는 경우 안내 메시지 표시

- **DB 확장 준비**:
  - `restaurants` 테이블에 음식점 주소 저장을 위한 `address` 컬럼 추가
  - 향후 지도 및 가상 배달현황 기능에서 사용할 음식점 위치 정보 저장 구조 준비

---

### 4주차: 사용자 배달 주소 및 가상 배달현황, 지도 API 연동

- **사용자 배달 주소 기능 구현**:
  - `users` 테이블에 사용자별 배달 주소를 저장하기 위한 `address` 컬럼 추가
  - 로그인한 사용자별 배달 주소 등록 기능 구현
  - 저장된 배달 주소 조회 및 수정 기능 구현
  - 비로그인 사용자의 배달 주소 설정 페이지 접근 제한
  - 메인 화면에서 배달 주소 설정 페이지로 이동할 수 있도록 메뉴 추가

- **주문 시 배달 주소 저장 기능 구현**:
  - 가상 주문 시 로그인한 사용자의 등록 주소 조회
  - 배달 주소가 등록되지 않은 경우 주소 설정 페이지로 이동
  - `orders` 테이블에 `delivery_address` 컬럼 추가
  - 주문 당시 사용자의 배달 주소를 주문 정보와 함께 저장
  - 이후 사용자가 주소를 변경하더라도 기존 주문의 배달 주소가 유지되도록 구현
  - 주문 상세 페이지에서 주문 당시 배달 주소 표시

- **가상 배달현황 기능 구현**:
  - 주문별 가상 배달현황 페이지 구현
  - 로그인한 사용자가 자신의 주문에 대한 배달현황만 조회할 수 있도록 처리
  - DB에 저장된 주문 시간을 기준으로 경과 시간 계산
  - 경과 시간에 따라 `주문 접수 → 음식 준비중 → 배달기사 배정 → 배달중 → 가상 배달 완료` 상태 표시
  - JavaScript를 이용하여 배달 상태를 주기적으로 갱신
  - 페이지를 새로고침하거나 다시 접속해도 주문 시간을 기준으로 현재 상태가 유지되도록 구현

- **카카오맵 API 연동**:
  - Kakao Developers 애플리케이션 생성 및 카카오맵 API 활성화
  - Flask 로컬 개발 환경을 JavaScript SDK 도메인으로 등록
  - 배달현황 페이지에 실제 카카오 지도 표시
  - Kakao Maps JavaScript SDK의 `services` 라이브러리 활용
  - 주문에 저장된 배달 주소를 Geocoder를 통해 위도·경도 좌표로 변환
  - 변환된 좌표를 기준으로 지도 중심 위치 이동
  - 사용자의 배달 위치에 지도 마커 표시

- **API 키 관리**:
  - 카카오맵 JavaScript 키를 `.env` 환경변수로 관리
  - Flask에서 환경변수의 키를 불러와 배달현황 페이지에 전달
  - API 키가 GitHub 소스코드에 직접 포함되지 않도록 분리
