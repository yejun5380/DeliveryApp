# DeliveryApp - 가상 배달 주문 & 절약 관리 웹 서비스

배달 앱 서비스 구조를 참고하여 제작한 **가상 주문 및 소비 절약 관리 웹 애플리케이션**입니다.

실제 결제나 배달 없이 가상 주문을 진행하고, 주문 금액과 칼로리를 각각 **절약한 금액**과 **절약한 칼로리**로 기록하여 사용자의 소비 절약 현황을 확인할 수 있습니다.

---

## 프로젝트 개요

- **프로젝트명**: DeliveryApp
- **개발 형태**: 2학기 개인 프로젝트
- **개발자**: 최예준
- **핵심 아이디어**: 실제 배달 주문 대신 가상 주문을 통해 불필요한 소비를 줄이고, 절약한 비용과 칼로리를 시각적으로 확인
- **주요 기능**: 회원 관리, 음식점 및 메뉴 조회, 장바구니, 가상 주문, 절약 통계, 가상 배달현황, 카카오맵 지도 및 거리 계산
- **서비스 범위**: 실제 결제 및 배달을 제공하지 않는 가상 서비스

### 7주차: 주문 음식점 위치 지도 표시 기능 구현

- **주문별 음식점 정보 조회**
  - `order_items`, `menus`, `restaurants` 테이블을 JOIN하여 주문에 포함된 음식점 조회
  - `DISTINCT`를 이용한 중복 음식점 제거
  - 주소가 `NULL`이거나 빈 문자열인 음식점 제외
  - 주문에 여러 음식점이 포함된 경우에도 각각 조회

- **Flask와 지도 데이터 연동**
  - `/delivery/<int:order_id>` 라우트에서 주문별 음식점 조회
  - 조회 결과를 `restaurants` 변수로 HTML 템플릿에 전달
  - 기존 사용자 주문 권한 확인 및 배달 주소 표시 기능 유지

- **카카오맵 다중 마커 구현**
  - Geocoder의 `addressSearch()`를 이용한 음식점 주소 좌표 변환
  - 음식점별 지도 마커 표시
  - 마커 클릭 시 음식점 이름 정보창 표시
  - 사용자 배달 주소 마커와 음식점 마커 동시 표시

- **지도 표시 개선**
  - `LatLngBounds`를 활용하여 전체 마커가 보이도록 지도 범위 자동 조정
  - 음식점이 여러 개인 주문도 지도에서 확인할 수 있도록 개선

---

### 8주차: 음식점별 직선거리 계산 및 가상 배달 가능 판정

- **음식점별 거리 계산**
  - 배달 주소와 음식점 주소를 좌표로 변환
  - Haversine 공식을 이용하여 두 좌표 사이의 직선거리 계산
  - 여러 음식점의 좌표를 관리하고 음식점별 거리 계산
  - 계산 결과를 km 단위, 소수점 둘째 자리까지 표시

- **가상 배달 가능 여부 판정**
  - 가상 배달 가능 거리 기준을 5km로 설정
  - 직선거리 5km 이하: `가상 배달 가능`
  - 직선거리 5km 초과: `가상 배달 범위 초과`
  - 음식점별 거리와 판정 결과를 배달현황 화면에 표시

- **좌표 처리 및 화면 개선**
  - 주소 검색 완료 후 거리 계산이 실행되도록 처리
  - 기존 지도 및 음식점 마커 기능 유지
  - 실제 도로 이동거리가 아닌 좌표 기준 직선거리임을 안내

- **구현 결과**
  - 특정 테스트 주문에서 맥도널즈와 배달 주소 사이 직선거리 약 3.75km 확인
  - 5km 기준에 따라 가상 배달 가능으로 판정
