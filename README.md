# DeliveryApp

배달앱을 기반으로 한 가상 주문 웹 서비스 프로젝트

## 프로젝트 소개

DeliveryApp은 실제 결제나 배달 없이 음식을 가상으로 주문할 수 있는 웹 서비스입니다.

사용자는 음식점을 선택하고 메뉴를 장바구니에 담아 주문할 수 있으며,
주문한 음식의 가격과 칼로리를 기록하여 누적된 절약 금액과 칼로리를 확인할 수 있습니다.

## 주요 기능

- 회원가입 / 로그인
- 음식점 목록 및 상세 정보
- 음식점별 메뉴 조회
- 장바구니
- 가상 주문
- 주문 내역 확인
- 누적 절약 금액 및 칼로리 확인


## 진행중

- users, restaurants, menus, orders, order_items 테이블 생성
- 음식점, 메뉴, 회원, 주문 기초 데이터 구축
- DB 구조 및 데이터 연동 정상 작동 확인
